KUWAGO Generador de firmas de correo

Datos

Recomendado: Claro. Algunos clientes de correo alteran los fondos oscuros en su modo noche.

Vista previa

Gmail (web)
  1. Pulsa «Copiar firma».
  2. Gmail → ⚙️ → Ver todos los ajustes → General → Firma → Crear nueva.
  3. Pega con Ctrl+V en el cuadro y guarda los cambios al final de la página.
Hostinger Webmail
  1. Pulsa «Copiar firma».
  2. Webmail → Ajustes → Identidades (o Firma) → elige tu dirección.
  3. Activa el modo de firma HTML si aparece la opción, pega con Ctrl+V y guarda.
  4. Si el editor solo acepta código, usa «Copiar HTML» y pégalo en el modo código fuente.
Outlook
  1. Pulsa «Copiar firma».
  2. Outlook web o nuevo: Configuración → Cuentas → Firmas → Nueva firma → pega y guarda.
  3. Outlook clásico: Archivo → Opciones → Correo → Firmas → Nueva → pega y acepta.

El logo se carga desde grupokuwago.com. Si la vista previa muestra el logo pero el correo recibido no, el archivo aún no se ha publicado en el sitio.
