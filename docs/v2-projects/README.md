# Proyectos reservados para V2

La V1 de la landing excluye la sección Projects / Proyectos, sus comparadores Antes/Después y el diálogo de detalle. Conserva las propiedades, sus galerías, el portafolio general, los contactos y el loader Curiosidad de 3,5 segundos.

Esta carpeta conserva copias verificadas del HTML, JavaScript, traducciones y CSS inmediatamente anteriores al retiro. Son referencias para recuperar el módulo, no archivos para reemplazar completos sobre versiones futuras del sitio.

Las fotos originales siguen en `assets/images/projects/` dentro del código fuente y en sus carpetas de origen. `scripts/build.mjs` las excluye de `dist/`. Esta carpeta de documentación también queda fuera del build. Para publicar, subir únicamente el contenido generado de `dist/`, no todo el repositorio.

Para V2: confirmar proyectos, estados y fotos; recuperar el módulo adaptándolo al código vigente; habilitar sus recursos en el build y actualizar la comprobación específica de V1. Revisar comparadores, teclado, tacto, idiomas y detalles antes de publicar.

Este cambio prepara la versión local y el paquete; no acredita un despliegue en el dominio.
