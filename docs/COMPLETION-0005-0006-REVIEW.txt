8. GARANTÍAS QUE SIGUEN SIN PODER OFRECERSE

- No es un bloqueo distribuido de todos los escritores, ni garantiza detectar un
  cambio transitorio revertido antes de las lecturas/guardas.
- Time Travel no se presenta como contador transaccional ni se atribuye cada
  avance a nuestra escritura. La nueva ventana puede detenerse por bookmark.
- No demuestra entropía real con una sola muestra de epoch: su origen es el SQL
  aprobado lower(hex(randomblob(16))) y la salida del mismo batch autenticado;
  se valida forma y preservación, no se inventa un valor esperado previamente.
- El ACK no prueba el instante de commit del servidor ni elimina una respuesta
  ambigua. El sistema conserva el estado desconocido y se detiene.
- No hay garantía global exactly-once contra otras herramientas/operadores; sí
  límites por ejecución, historial, guards y ausencia de reintentos automáticos.
- La durabilidad de fsync/DPAPI depende de Windows/disco/perfil y no sustituye el
  backup/recuperación externos; no se promete borrado físico absoluto de memoria.
- El journal de simulación usa directorios temporales locales. Su inyección de fallo
  está prohibida en development. Un transporte remoto no coincide con entorno
  local-simulation, y el CLI real no acepta configuración ni IDs arbitrarios.
- El flujo se limita a la instalación vacía confirmada de etapa 4. Un catálogo con
  datos o cambios requiere otro plan; no se adapta silenciosamente.
- No se probó nada remotamente en esta entrega; no se verifican aquí permisos de
  un futuro token, infraestructura nueva o semántica adicional de servicios.
